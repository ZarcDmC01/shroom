## Résumé : Classification des champignons avec PySpark

### Objectif
Ce projet guide l'utilisateur dans la création d'un modèle de classification pour déterminer si un champignon est comestible ou toxique en utilisant PySpark. Il inclut l'exploration des données, la construction d'un modèle, son évaluation et la sauvegarde du meilleur modèle.

### Étapes clés
1. **Exploration des données** : Analyse du jeu de données sur les champignons (source : Kaggle).
2. **Création du modèle** : Utilisation de PySpark ML pour entraîner un classifieur (choix libre de l'algorithme).
3. **Évaluation** : Comparaison des performances des modèles (métriques comme précision, rappel).
4. **Sauvegarde** : Sélection du meilleur modèle et création d'une API REST pour le déployer.
